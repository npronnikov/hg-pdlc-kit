# Документация продукта

`product/` — принятая база существующего продукта. `changes/<change-id>/` — изолированное согласуемое изменение. Это постоянные артефакты: включайте их в Git, review и контроль конфликтов. Run state здесь не хранится. `.hgsdlc/` обслуживает платформа и не коммитится; не копируйте туда процесс вручную.

Не называйте target architecture текущей до фактической интеграции. Завершённый feature-flow оставляет verified-not-integrated change package. После merge отдельный процесс актуализирует product baseline; он не входит в поставленную границу.
