# Контекст продукта

## Назначение и границы
Заполняется из доступных продуктовых источников и интервью. Не выводить бизнес-цель как факт только из кода.

## Реестр источников
Для каждого источника: repo, commit/revision, path/anchor, observed_at, authority, applicability.

## Правила команды
Только подтверждённые правила, рабочие команды и запрещённые зависимости. Не заменять существующий AGENTS.md; ссылаться на него и выявлять противоречия.

## База знаний
Бизнес: business/; архитектура: architecture/; системные требования: system/; тестовая модель: tests/; связи: trace/.

До bootstrap это шаблон, а не подтверждённое описание системы.
