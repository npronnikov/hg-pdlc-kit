# Анализ без скрытой установки
Приоритет: доступные file search / rg / git grep / manifests / исходники и тесты.
Repomix — опциональное средство локального context packing, только если уже установлено и разрешено средой.
Не делать network install внутри flow; не отправлять секреты/персональные данные/всю монорепу внешнему сервису.
Raw pack — run scope, никогда не каноническая спецификация. Факты проверять по исходным path/commit.
