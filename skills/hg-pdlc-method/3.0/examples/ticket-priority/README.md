# Сквозной пример: приоритет заявки
- `before/` — исходный минимальный monorepo для brownfield.
- `project/` — полезный целевой снимок: PRD/архитектура/SRS/тестовая модель/код/E2E/evidence.
- `run-scope/` — экспорт промежуточных артефактов по узлам, НЕ папка для копирования в product workspace.
- `greenfield.md` — прохождение того же класса задачи с пустого Git-корня.
- Полный сценарий в [WALKTHROUGH](../../../../../docs/WALKTHROUGH.md).

Нарратив, интервью, approval и индексы подготовлены как учебные fixtures. Только logs/receipts/report из команд
отмечены как фактически выполненные проверки. В живом HG SDLC AI/subagent/human переходы здесь не запускались.
Не копировать одновременно before и project в одно приложение: это входной и выходной снимки одной монорепы.
